# Ascii Forge

A 100% client-side web application that converts images and live video feeds into retro, colorized ASCII art. 

## Features
- 🖼️ Image & Video to ASCII conversion
- 🎨 Full RGB Color ASCII rendering
- 📷 Live Webcam integration
- ⌨️ Custom character set mapping
- 💾 Export to TXT, PNG, and WebM video
- 📺 Retro CRT Terminal UI with scanlines

## Tech Stack
- Vanilla HTML5 / CSS3 / JavaScript
- HTML5 Canvas API for high-performance rendering
- Web APIs: `getUserMedia`, `MediaRecorder`, `File API`

## How to Run
No build tools required! 
1. Clone the repo.
2. Open `index.html` in any modern web browser.
